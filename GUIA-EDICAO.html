1Como funciona

Antes, para atualizar o site era preciso editar arquivos HTML. Agora, todo o conteúdo está em UMA planilha Excel chamada database.xlsx.

Quando alguém visita o site, o navegador carrega essa planilha automaticamente e monta as páginas com as informações dela.

O que isso significa para você

  • Não precisa saber HTML, CSS ou JavaScript
  • Pode editar do Excel comum, do Google Sheets ou do LibreOffice
  • Atualiza várias coisas de uma só vez
  • Não corre risco de quebrar o site mexendo em código

3Fluxo de atualização

Sempre que precisar atualizar qualquer coisa do site:

1

Baixe o database.xlsx do servidor

Pegue a versão mais atual da planilha que está hospedada no servidor.

2

Abra no Excel (ou LibreOffice)

Vá para a aba que precisa editar — por exemplo, projetos para adicionar um projeto novo.

3

Edite, adicione ou remova linhas

Não altere os cabeçalhos da primeira linha. Use o próximo número disponível na coluna id ao adicionar.

4

Salve mantendo o nome database.xlsx

O nome precisa ficar exatamente igual. No Excel: Arquivo → Salvar (não Salvar Como).

5

Suba o arquivo no servidor

Substitua o database.xlsx antigo pelo novo, na mesma pasta dos arquivos HTML. Pronto: o site já está atualizado para todos.

Dica: faça um backup antes

Antes de subir a versão nova, salve o arquivo antigo do servidor com outro nome (ex.: database-2025-05-01.xlsx). Assim, se algo der errado, você consegue voltar.

4Regras importantes

Coisas que NÃO devem ser feitas

  • Não renomeie as abas (planilhas)
  • Não altere os nomes dos cabeçalhos da primeira linha
  • Não delete a aba _INSTRUCOES nem config
  • Não repita números de id na mesma aba
  • Não mude a coluna chave na aba config

Coluna "id"

Toda aba tem uma coluna id com um número único. Para adicionar um item novo:

  1. Olhe o maior número que já existe na aba
  2. Use o próximo número (se o maior é 18, o novo é 19)
  3. Não pule números nem repita

Colunas tipo "destaque"

Algumas colunas funcionam como sim/não:

  • Para SIM: digite 1
  • Para NÃO: deixe em branco (ou digite 0)

Coluna "ordem"

Define em que posição o item aparece no site. Use 1 para o primeiro, 2 para o segundo, e assim por diante. Itens com a mesma ordem aparecem na ordem em que estão na planilha.

5Campos especiais

Alguns campos guardam várias informações em uma célula só. Use os separadores certos:

Listas simples (vírgula)

Para palavras-chave, tags, etc. Use vírgula:

Cerrado, Sensoriamento Remoto, Maranhão, Desmatamento

Várias linhas (Alt+Enter)

Para objetivos numerados ou parágrafos. Use Alt+Enter dentro da célula para quebrar linha:

Mapear a cobertura vegetal do Cerrado
Quantificar as taxas de desmatamento
Avaliar a fragmentação da paisagem

Listas com várias propriedades (| e ;)

Para equipe, cronograma, financiamento. Cada item é separado por ponto-e-vírgula ;, e cada propriedade dentro do item é separada por barra vertical |.

Equipe (formato: Nome|Papel)

João Silva|Coordenador; Ana Costa|Pesquisadora; Carlos Mendes|Doutorando

Vai aparecer no site como 3 cards de membros separados.

Cronograma (formato: Periodo|Titulo|Descricao|Status)

2021-2022|Levantamento|Revisão da literatura|concluida; 2023-2024|Análise|Cálculo de métricas|atual; 2024-2025|Publicação|Artigos científicos|futura

Status válidos: concluida, atual, futura.

Financiamento (formato: Sigla|Descrição|Valor)

CNPq|Fomento à pesquisa|Edital Universal; UFMA|Infraestrutura|Apoio institucional

Aba: parceiros, documentarios, slides_home

Estruturas simples, com colunas auto-explicativas. Veja o comentário no cabeçalho de cada aba (passe o mouse sobre a célula A1).

Aba: config (chave/valor)

Atenção: NÃO altere a coluna "chave"

A primeira coluna (chave) é o "código" que conecta a planilha ao site. Se você renomear a chave, o site não vai encontrar mais o valor. Edite só a coluna valor.

7Problemas comuns

"O site não atualizou depois que subi a planilha"

O navegador pode estar mostrando uma versão em cache. Aperte Ctrl + F5 (ou Cmd + Shift + R no Mac) para forçar o navegador a baixar tudo do zero.

"Aparece 'Erro ao carregar database.xlsx'"

  • O arquivo precisa estar na mesma pasta dos HTMLs no servidor
  • O nome precisa ser exatamente database.xlsx (tudo minúsculo, sem espaço)
  • Se renomeou sem querer, renomeie de volta

"Adicionei um projeto e ele não aparece"

  • Conferiu se preencheu a coluna status com andamento ou concluido?
  • Conferiu se o id não está repetido?
  • Conferiu se salvou e subiu a versão nova?

"O cronograma/equipe ficou bagunçado"

Verifique se está usando os separadores certos:

  • Entre itens: ponto-e-vírgula ;
  • Entre propriedades de um item: barra vertical |

Em caso de dúvida

Olhe o exemplo que já está cadastrado em cada aba como modelo. Os primeiros registros foram preenchidos como exemplo justamente para você usar como referência.
